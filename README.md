# 위클리랩 | Weekly Lab

**반복되는 업무를 줄이고, 필요한 시스템을 만듭니다.**

위클리랩은 웹사이트, 업무 관리 시스템, 서비스 연동과 자동화를 개발합니다.
엑셀로 옮겨 적는 일, 여러 서비스에서 따로 확인하는 정보, 기존 시스템의 불편을 살펴보고 실제 업무에 맞는 소프트웨어를 만듭니다.

## 하는 일

- **웹사이트와 관리자 화면**: 담당자가 소식, 일정, 사진과 안내 내용을 직접 관리할 수 있는 화면을 만듭니다.
- **업무 관리와 자동화**: 명단, 재고, 주문, 보고서를 한곳에서 관리하고 반복 작업을 줄입니다.
- **외부 서비스 연동**: 로그인, 결제, 알림, 파일 저장과 외부 데이터를 업무 흐름에 연결합니다.
- **기존 시스템 개선**: 느린 조회, 데이터 불일치, 반복되는 오류를 살피고 필요한 기능 개선과 이전을 진행합니다.

## 운영하는 서비스

### 위클리스쿨

주일학교의 학생 명단과 출석을 관리하는 서비스입니다.
엑셀 명단 가져오기, 모바일 출석 기록, 통계 확인과 조직별 접근 권한 관리를 제공합니다.

[위클리스쿨 살펴보기](https://weekly-school.site/landing)

## 구축/개발 사례

실제 업무에 필요한 기능을 만들고 개선해 왔습니다.

- **재고와 발주 자동화**: 현재 재고, 배송 중 수량과 도착 예정일을 반영한 발주 판단, 거래명세서와 엑셀 일괄 처리
- **검색 시스템 이전과 개선**: 기존 호출 방식을 유지한 검색 API 이전, 검색 데이터 검증과 불일치 조사
- **인증과 물류 서비스 연동**: 공개키 기반 인증, 번역, 환율 갱신과 배송 조회, 데이터베이스와 서버 이전
- **데이터 취합과 보고서 자동화**: 외부 데이터의 주기적 수집, 이메일 알림과 엑셀 보고서 생성
- **홈페이지와 콘텐츠 관리**: 콘텐츠 편집과 게시, 운영 알림을 위한 홈페이지 및 관리자 화면 구축 진행

## 함께 일하는 방식

먼저 현재 업무와 필요한 기능을 듣고, 화면과 시안으로 만들 범위를 구체화합니다.
작업 범위, 일정, 금액과 검수 기준을 합의한 뒤 개발하며, 중간 결과를 함께 확인합니다.
검수와 보완을 거쳐 공개하고, 담당자에게 관리 방법을 안내합니다.

구축 비용과 이후의 서버 및 외부 서비스 운영 비용을 함께 살핍니다.
추가 요청이나 변경이 생기면 일정과 비용에 미치는 영향을 먼저 협의합니다.
